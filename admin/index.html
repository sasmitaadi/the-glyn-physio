Panduan langkah demi langkah untuk mengelola website The Glyn Physio.

Mulai dari sini

Gunakan menu di sebelah kiri untuk berpindah fitur. Setelah menyimpan perubahan, buka website dan lakukan refresh untuk memeriksa hasilnya.

01

Konten

Artikel, layanan, dan halaman publik.

02

Kontak

Nomor HP, email, Maps, jam buka, dan sosial media.

03

Analytics

Melihat kunjungan dan klik penting.

1 Cara menambah atau mengedit konten
  1. Buka menu Konten.
  2. Klik Content baru untuk membuat data atau Edit pada baris yang sudah ada.
  3. Isi judul, tipe konten, status, ringkasan, dan isi.
  4. Pilih dan isi media langsung di form fitur terkait.
  5. Pilih Tayang, lalu klik Simpan.

Slug konten lama dipertahankan ketika diedit agar link yang sudah dibagikan tidak rusak.

2 Cara mengubah kontak dan jam buka
  1. Buka menu Kontak & sosial.
  2. Pilih Kelola informasi untuk email, nomor HP, alamat, dan Google Maps.
  3. Pilih Kelola jam buka untuk mengatur jadwal setiap hari.
  4. Gunakan Tambah kontak untuk WhatsApp atau akun sosial media lainnya.
3 Cara membaca analytics

Menu Analytics menampilkan pengunjung unik, page view, klik kontak, dan artikel yang dibaca selama 30 hari.

4 Cara mengelola pengguna
  1. Buka menu Pengguna.
  2. Admin dapat menambah akun atau mengedit nama, email, role, status, dan kata sandi.
  3. Segera nonaktifkan akun yang sudah tidak digunakan.
5 Jika perubahan belum terlihat
  1. Pastikan tombol Simpan berhasil.
  2. Refresh website menggunakan Ctrl + F5.
  3. Periksa status konten sudah Tayang.
  4. Pastikan MySQL dan server localhost aktif.
Catatan penting

Dashboard tidak menyediakan page builder atau penambahan section halaman secara bebas. Kelola media langsung melalui form Artikel, Spesialisasi, Testimoni, Sesi Terapi, serta Tentang, Tim & Fasilitas.
